# NVIDIA Isaac Sim 6.0 examples

These examples are copied from NVIDIA Isaac Sim `v6.0.0`, commit
`40316786340b3f034a229d9e12650df1ac0b68ab`, under
[`source/standalone_examples`](https://github.com/isaac-sim/IsaacSim/tree/v6.0.0/source/standalone_examples).
The upstream license headers are retained. Examples using APIs deprecated in
6.0 live in `deprecated/`, matching upstream. Examples removed upstream are no
longer included here; their previous versions remain in AirStack Git history.

These are upstream reference examples, not the RAVEN application or its smoke
test. Run RAVEN using `../launch_scripts/` and validate its integration using
`../tests/smoke_isaac6.py`. Run examples with Isaac Sim's `python.sh`, not the
host Python interpreter. Some examples require additional assets or hardware.
